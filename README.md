# Blackbox Gas

Lernwebsite zur Chemie-Übung „Luft und Gasnachweise" (Chemie 8, Gymnasium Bayern).

- `index.html` – die komplette Seite (Auftrag, Sicherheit, Steckbriefe, Werkzeuge, Tipps, Auflösung, digitaler Versuch zum Sauerstoffanteil, Check)
- `videos/` – Videos zu Glimmspan-, Knallgas- und Kalkwasserprobe
- `AB_Blackbox_Gas_und_Luft.pdf` – Arbeitsblatt für das digitale Heft
